Spec UI Project

This sub-project is a static UI for the HCCL project where we will try out new UI concepts without
trying to wire them up.  I want to use these uistarter components as a starter kit.
Just use fake data and get the components in there so we can take a look at them.
We want to use this to work out all the style sheet issues. 

We want to make this site a complete template and example for all types of pages and styles and component.

Style sheet:
./uistarter.scss - standardized style sheet - containing all the styles - use this for all the components pages.

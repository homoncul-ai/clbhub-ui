## Special Considerations
- `teamParentId`, `teamParentEntityType`, and `teamParentName` are treated as plain string fields, not foreign keys
- Import `TeamTypeRefCrudComponent` and `HcclOrganizationCrudComponent` for foreign key fields
- Use `app-std-mdb-text` for the parent-related fields instead of foreign key components

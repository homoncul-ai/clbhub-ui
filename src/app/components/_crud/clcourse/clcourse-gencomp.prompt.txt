## Common Issues and Solutions

- Ensure all required components are imported in the `@Component.imports` array
- For date display components, import `DategetdataDisplayComponent`
- For available selector, import `AvailableSelectorComponent`
- For menu controls, import `MenuControlDataListComponent`

### Template Binding Errors
- Ensure `@Input()` properties are declared in component classes
- For date components, ensure `@Input() dateData: any` is declared
- For available selector, ensure proper two-way binding with `[(ngModel)]`
- Check that all form field bindings use correct property names

### Routing Issues

- Use consistent route naming: `/ecoadmin-dashboard/integration_edu/clcourse-list` for eco-admin

- **Do NOT** inject `Router` or `HcclService` in Group component constructor

### DHTMLX Integration

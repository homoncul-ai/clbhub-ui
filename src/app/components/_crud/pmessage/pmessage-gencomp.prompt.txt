# PMessage Component Generation Specification

## Entity Information
- **Entity Name:** PMessage
- **Plural Route Name:** pmessages
- **Reference Example:** Based on HcclOrganization template

## Generated Components

### 1. CRUD Component (`pmessage-crud.component.ts` & `pmessage-crud.component.html`)
- **Purpose:** Display, edit, and add PMessage data
- **Extends:** `AbstractCrudComponent<PMessageCrudWrapper>`
- **Wrapper Class:** `PMessageCrudWrapper extends EntityWrapper<PMessageGETData>`

#### Key Attributes:
- `authorUserProfileId` (FK to HcclUserProfile)
- `title` (string, required)
- `description` (string, textarea)
- `subjectEntityId` (string)
- `subjectEntityType` (string)
- `subjectEntityName` (string, read-only)
- `dateLastEntry` (date)

#### Service Methods Used:
- `HcclService.getPMessageById(id)`
- `HcclService.createPMessage(body)`
- `HcclService.updatePMessageById(id, body)`
- `HcclService.findPMessages(criteria)`

#### Foreign Key Handling:
- **Author User Profile:** Uses `<app-hccluserprofile-crud>` component for FK display

### 2. Group Component (`pmessage-group.component.ts` & `pmessage-group.component.html`)
- **Purpose:** Router target to group all tabs for PMessage (details, list)
- **Extends:** `AbstractEntityGroupComponent<PMessageCrudWrapper>`
- **Tabs:** Details and Create tabs

### 3. List Component (`pmessage-list.component.ts`)
- **Purpose:** Router target to search and list PMessageGETData
- **Extends:** `AbstractListComponent<PMessageGETData, PMessageCriteria, PMessageGETDataSearchResults>`
- **Template:** Uses abstract list template (no custom template file)

#### Grid Columns:
- Title (filterable)
- Description (filterable)
- Subject Entity Name (filterable)
- Subject Entity Type (filterable)
- Author User Profile (FK display)
- Date Last Updated

#### Foreign Key Formatting:
- `authorUserProfileStr`: Displays HcclUserProfile display text

## Route Configuration
- **List Route:** `/ecoadmin-dashboard/pmessages`
- **Create Route:** `/ecoadmin-dashboard/pmessages/create`

- **Default Redirect:** `/ecoadmin-dashboard/pmessages/:id` → `/ecoadmin-dashboard/pmessages/:id/details`

# Entity Specification — Cohort MVP **Source:** `citizen/cohorts` participant UI wireframes (Healthcare Careers + AI Exploration presets), MVP prompt, and existing `Cohort` / `Participant` / `PMessage` platform entities. **Purpose:** Propose a relational entity model that supports the participant tabs — **My Cohort**, **Activities**, **Resources**, **Community**, **My Progress**, and **Setup** — without over-building beyond MVP. --- ## 1. Conceptual model A **Cohort** is a time-bounded learning group with a **pathway topic**, **milestone phases**, a **sequenced curriculum** (periods → activities), a **resource library**, **cohort-scoped messaging**, and **per-participant** progress, goals, consents, and notifications. ### 1.1 Entity relationship diagram ```mermaid erDiagram CohortType ||--o{ Cohort : classifies Cohort ||--o{ CohortPhase : has Cohort ||--o{ CohortPeriod : schedules Cohort ||--o{ CohortActivity : defines Cohort ||--o{ CohortResource : library Cohort ||--o{ CohortMember : enrolls Cohort ||--o| PMessage : cohort_channel CohortPhase ||--o{ CohortPeriod : optional_span CohortPeriod ||--o{ CohortActivity : contains CohortActivity ||--o{ CohortActivityResource : attaches CohortActivity ||--o{ CohortMemberActivity : tracks CohortMember ||--o{ CohortMemberActivity : performs CohortMember ||--o{ CohortMemberGoal : sets CohortMember ||--o{ CohortMemberConsent : consents CohortMember ||--o{ CohortMemberNotificationPref : prefers CohortMember ||--o{ CohortOnboardingStep : completes CohortMember ||--o| PMessage : leader_dm CohortMemberActivity ||--o{ CohortActivityResourceView : viewed CohortMember ||--o{ CohortCheckInResponse : submits Cohort ||--o{ CohortCheckIn : publishes CohortCheckIn ||--o{ CohortCheckInResponse : collects Cohort ||--o{ CohortNotification : emits CohortMember ||--o{ CohortMemberNotification : receives ``` **Legend:** Solid boxes below are **existing platform entities** (extend or link).

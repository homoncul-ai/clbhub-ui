# CLBHub Haverhill Summer Jobs MVP Document **CLBHub Haverhill** connects Haverhill students with summer jobs, internships, classes, and camps via a vocational-focused platform. The MVP targets a *summer 2026 launch*, integrating with Haverhill Helps, to maximize student placements while tracking metrics for iteration. Providers (businesses/nonprofits/schools) manage opportunities; families/students browse and apply. Core value: Frictionless matching prioritizing transit access, travel time, and student skills/interests, with admin oversight for quality. ## Goals and Success Metrics **Primary Goal**: Place 100+ Haverhill students in summer opportunities by August 2026. **Key Metrics**: | Metric | Target | Tracking Method | |-------------------|-----------|--------------------| | Student signups | 500+ | Dashboard count | | Opportunities listed | 200+ | Provider catalog | | Placement rate | 20%+ | Hired/accepted status | | Completion rate | 80%+ | End-of-summer check-ins | | Feedback NPS | 7+ | Post-placement surveys | | Provider retention| 70%+ | Returning listings | Feedback loops enable yearly improvements; all roles can submit via simple forms. ## User Roles and Permissions Two classes: **App Users** (providers/families/students) and **Ecosystem Managers** (wranglers/admins/counselors). | Role | Key Actions | Permissions | |-----------------------|---------------------------------------|------------------------------------| | **Families/Parents** | Onboard students; opt into guidance | Manage profiles; communicate | | **Students** | Self-onboard; view/filter opps by map | Apply; rate experiences | | **Guidance Counselor**| Review student paths; field tickets | Approve apps; add notes | | **ProviderAdmin** | Create/edit listings (dates, paid/unpaid) Interact with students; | Add catalog entries; view stats | | **ProviderSme** | run classes | View assigned students; check-ins | | **Mentor** | Mentor Students; | View assigned students; check-ins | | **ClbhubAdmin** | Validate onboardings; coordinate recruitment | Full access; dispute resolution | *Roles scale via ratios (e.g., 1 wrangler:10 providers; 1 counselor:50 students).* ## MVP Features Prioritize table-stakes essentials for launch.

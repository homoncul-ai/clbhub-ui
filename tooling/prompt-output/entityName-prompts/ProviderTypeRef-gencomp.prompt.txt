# ProviderTypeRef Component Generation Spec

This spec describes the requirements for generating the CRUD, List, and Group Angular components for the entity **ProviderTypeRef**. The components will be generated in `src/app/components/_crud/providertyperef/` and will use the global SCSS file (empty local .scss files).

## CRUD Component

- **Purpose:** Display, edit, and add ProviderTypeRef data.
- **Files:**
  - `providertyperef-crud.component.html`
  - `providertyperef-crud.component.ts`
  - `providertyperef-crud.component.scss` (empty)

## Notes for Future Updates

- This spec is designed to be **idempotent**: you can update and re-apply it to safely update the generated components.
- When updating, ensure all new requirements are reflected in the attribute tables and method call instructions.
- Keep the spec clear, concise, and easy to review for both humans and AI.
- All generated components should use the global SCSS file and have empty local .scss files.
- All files reside in `src/app/components/_crud/providertyperef/`.
- The CRUD component should call the appropriate methods in HcclService for ProviderTypeRef.
- The Group and List components should be based on the structure and logic of the CLStudentGroup and CLStudentList components, respectively.

* app-provider-dashboard-group  -    
 The tabset will have  these tabs : 
   - tab 1 - app-provider-dashboard-tab-mydash :  Tiled dashboard with the following tabs. 
	 a. Tile 1 - stats on number of "provider requests" - new, in-progress, closed 
	 b. Tile 2 - pie chart of number of course catalog interests, by catalog.  
	 c. Tile 3 - List of all the catalogs, with the number of entries.
   

 
* app-provider-details-group  - group show the information about the  organization  
  The tabset will have these tabs :
  - app-provider-details-tab-myschool - My school - name of school as the first tab. 
  - app-provider-details-tab-myschool - Colleagues 
 
* app-provider-workrequest-group 
   The tabset will have  these tabs : 
   - tab 1 - app-provider-workrequest-tab-dash  - A tiled dashboard with the following tiles
     -  Tile 1 - Action required  (shows a short list of tickets - display each one usint <app-workrequest-crud multiMode='section'>
     


* app-provider-catalog-group  - group show the information about the  catalogs  
  The tabset will have these tabs : 
   - tab 1 : app-provider-catalog-tab-dash :  Tiled dashboard with a tile for each catalog displayed using component <app-catalog-crud>

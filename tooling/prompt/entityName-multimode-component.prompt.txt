[folderName] - the folder to put the new component 
[componentClassName] - the class name of the component
[groupComponentName] - the component that needs to have the tab [tabName]. 
[entityName] - specifies the '_crud/[entityName]' folder you'll find the components/objects in.
[tabName] - specifies the name of the tab to be used in the routing module.

-- generate the component .ts, .html file name based on the componentClassName, with proper angular conventions
-- create the generated .ts, html file in [folderName]

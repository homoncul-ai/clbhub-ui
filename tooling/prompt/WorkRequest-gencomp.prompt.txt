## Route Configuration

### Route Structure
- **List**: `/ecoadmin-dashboard/workrequests`
- **Create**: `/ecoadmin-dashboard/workrequests/create`
- **Details**: `/ecoadmin-dashboard/workrequests/:id/details`
- **Edit**: `/ecoadmin-dashboard/workrequests/:id/edit`

### Module Integration
Add to `dash-ecoadmin.module.ts`:
```typescript
{ path: 'workrequests', component: WorkRequestListComponent },
{ path: 'workrequests/create', component: WorkRequestGroupComponent },
{ path: 'workrequests/:id/:tabId', component: WorkRequestGroupComponent },
{ path: 'workrequests/:id', redirectTo: 'workrequests/:id/details', pathMatch: 'full' }
```

## Common Issues and Solutions

### Component Import Errors
- Ensure all required components are imported in the `@Component.imports` array
- For date display components, import `DategetdataDisplayComponent`
- For available selector, import `AvailableSelectorComponent`
- For menu controls, import `MenuControlDataListComponent`.
  for example - in the "FK_MENU" template - use this : 
```
<app-menu-control-data-list [menuControlDataList]="this.fkMenu" [id]="this.id"></app-menu-control-data-list>

```
- **CRITICAL:** For date components, ensure `@Input() data: any` is declared in the component class

### Template Binding Errors
- Ensure `@Input()` properties are declared in component classes
- For date components, ensure `@Input() data: any` is declared
- For available selector, ensure proper two-way binding with `[(ngModel)]`
- Check that all form field bindings use correct property names

### Routing Issues
- **CRITICAL:** Ensure route paths match between module configuration and menu constants
- Use consistent route naming: `/ecoadmin-dashboard/[routePath]` for eco-admin (not `/ecoadmin/[routePath]`)
- Include proper redirects for default tab navigation
- Menu routes must match actual app routing structure

### Constructor Dependencies
- **CRUD Components:** Only inject `super()` - no additional services needed
- **Group Components:** Only inject `ActivatedRoute` in constructor
- **List Components:** Inject `HcclService`, `ActivatedRoute`, `Router`
- Always call `super()` in constructor for components extending abstract classes
- **Do NOT** inject `Router` or `HcclService` in Group component constructor

### AbstractListComponent Integration
- **CRITICAL:** List components MUST extend `AbstractListComponent` not implement `OnInit`
- **DO NOT** include `declare const dhx: any;` - handled by abstract base class
- **DO NOT** include manual DHTMLX grid initialization - handled by abstract base class
- **DO NOT** create custom template or stylesheet files - use abstract list template
- Copy ALL abstract method implementations from `copyFromEntity-list.component.ts`
- Use plural route names for navigation (e.g., '/ecoadmin-dashboard/clcourses')

### Menu Navigation Issues
- **CRITICAL:** Menu route must match actual app routing structure
- For eco-admin dashboard, use `/ecoadmin-dashboard/[routePath]` not `/ecoadmin/[routePath]`
- Ensure menu constants use correct route paths
- Test navigation after menu integration

### Component Structure Issues
- **CRITICAL:** Copy ALL methods from reference components [copyFromEntity]
- Do not create new methods - use existing patterns
- Ensure proper inheritance from abstract classes
- Include all required abstract method implementations

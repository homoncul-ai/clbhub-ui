## Route Naming Convention

### Pluralization Rules
- **Ends in "y":** Add "ies" (e.g., "entry" → "entries")
- **Ends in "f":** Change to "ves" (e.g., "leaf" → "leaves")
- **Default:** Add "s" (e.g., "catalog" → "catalogs")

### Examples
- entityName = "catalog" → route = "catalogs"
- entityName = "clcourse" → route = "clcourses"
- entityName = "providertyperef" → route = "providertyperefs"
- entityName = "someEntry" → route = "someEntries"

### Route Structure
- **CRITICAL:** Never include package prefixes in routes
- Use: `/ecoadmin-dashboard/[pluralEntityName]` (not `/ecoadmin/[pluralEntityName]`)

## Common Issues & Solutions

### Component Import Errors
- Ensure all required components are imported in `@Component.imports` array
- For date components, ensure `@Input() data: any` is declared
- For menu controls, use: `<app-menu-control-data-list [menuControlDataList]="this.fkMenu" [id]="this.id"></app-menu-control-data-list>`

### Template Binding Errors
- Ensure `@Input()` properties are declared in component classes
- For available selector, ensure proper two-way binding with `[(ngModel)]`
- Check that all form field bindings use correct property names

### Routing Issues
- **CRITICAL:** Ensure route paths match between module configuration and menu constants
- Use consistent route naming: `/ecoadmin-dashboard/[routePath]` for eco-admin
- Include proper redirects for default tab navigation

### Constructor Dependencies
- **CRUD Components:** Only call `super()` - no additional services needed
- **Group Components:** Only inject `ActivatedRoute` in constructor
- **List Components:** Only call `super()` - no additional services needed
- Always call `super()` in constructor for components extending abstract classes

### AbstractListComponent Integration
- **CRITICAL:** List components MUST extend `AbstractListComponent` not implement `OnInit`
- **DO NOT** include `declare const dhx: any;` - handled by abstract base class
- **DO NOT** include manual DHTMLX grid initialization - handled by abstract base class
- **DO NOT** create custom template or stylesheet files - use abstract list template
- Copy ALL abstract method implementations from `copyFromEntity-list.component.ts`

- This prompt will be used to generate a spec for Cursor to generate a set of 3 angular components.  
- The output from this prompt will be another prompt be called src/app/components/_crud/[entityName]/[entityName]-gencomp.prompt.txt
- The spec will be markdown. 
    - After creation of the spec, someone will be editing and massaging spec before the actual generation. 
    - Ultimately, the file [entityName]-gencomp.prompt.txt will be used to generate the CRUD, List, and Group components

- Each component set will be based on an "entityName" that will be passed in as an argument.
- The components generated will be based on some working examples in the project.
- The components will call into the appropriate  methods in HcclServices. 
- All component files will reside in the folder src/app/components/_crud/[entityName]
- each component will have all its files in  the folder src/app/components/_crud/[entityName].
- Do not create a new folder for each crud component.
- All the components generated need to rely on the global scss file, and will have empty .scss file.

### Section - Details - 

based on HcclService interface [entityName]GETData

Example : 

export interface CatalogSearchResultGETData {
  id?: string;
  createdByInfo?: Reference;
  dateCreated?: DateGETData;
  lastUpdatedByInfo?: Reference;
  dateLastUpdated?: DateGETData;
  catalogId?: string;
  comments?: string;
  subjectEntityId?: string;
  subjectEntityType?: string;
  subjectEntityName?: string;
  parentWorkRequestItemId?: string;
}


    - Specify the list of attributes to display for Details in tabular format.
    - id should always be the first
    - createdByInfo, dateCreated, lastUpdatedByInfo, dateLastUpdated should always be last.
    - for each field show the attrName, type, the label, and any special hit about displaying it.
    - dates should be displayed using the app-dategetdata-display component
    - If there are 3 attributes of the form [prefix]EntityId, [prefix]EntityType, [prefix]EnityName, display using  component app-efk .
     Example : 
            subjectEntityId?: string;
            subjectEntityType?: string;
            subjectEntityName?: string;

	"<app-efk-display id="this.subjectEntityId" name="this.subjectEntityName" type="this.subjectEntityType" >"
     - Any other attributes of the form [prefix]Id are foreign key element. They should be displayed like "<app-[fkEntityName]-crud id="this.[fkEntityName]Id" mode="CrudModes.FK".  Resolve the best guess for the fkEntityName referring to HcclService for the list of Interfaces. 
      - DOn't worry if the crud-component doesn't exist in the project yet.  We'll be generating them all. 
       From Above example.
	  parentWorkRequestItemId?: string;
          The fkEntityName is "WorkRequestItem"

# ProviderTypeRef Component Generation Spec

This spec describes the requirements for generating the CRUD, List, and Group Angular components for the entity **ProviderTypeRef**. The components will be generated in `src/app/components/_crud/providertyperef/` and will use the global SCSS file (empty local .scss files).

#### Attributes Table (Details)
| Attribute         | Type         | Label           | Display Hint |
|-------------------|--------------|-----------------|--------------|
| id                | string       | ID              | Always first |

| businessCode      | string       | Business Code   |              |

| createdByInfo     | Reference    | Created By      | Always last  |
| dateCreated       | DateGETData  | Date Created    | Use `<app-dategetdata-display>` |
| lastUpdatedByInfo | Reference    | Last Updated By | Always last  |
| dateLastUpdated   | DateGETData  | Date Last Updated | Use `<app-dategetdata-display>` |

- **Order:**
  - `id` first
  - `createdByInfo`, `dateCreated`, `lastUpdatedByInfo`, `dateLastUpdated` last
  - All others in between
- **Display:**
  - Dates: Use `<app-dategetdata-display>`
  - No foreign key or EFK patterns in this entity
